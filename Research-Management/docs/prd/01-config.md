# PRD-01 · 配置页面（用户权限 + 自定义选项）

> 投研系统的底座模块。定义"谁能登录、什么角色、能干什么"，以及"研报评级/观点等可扩展枚举怎么维护"。是②③④⑤所有业务模块的权限与配置来源。

**状态**：草案 v1
**最近更新**：2026-08-11

---

## 1. 目标与范围

本模块包含两个子系统：

- **子系统 A：用户与权限管理** —— 管理账号、角色、角色-权限点关系
- **子系统 B：自定义选项管理** —— 维护可扩展枚举库（评级、观点、出池原因等），通用配置中心

不在本模块范围：行业/研究员档案的专业属性（→ ②）、具体业务数据的增删改（→ ③④⑤）。

---

## 2. 核心概念：多角色 + 权限取并集

一个用户可绑定 **N 个角色**，最终权限 = 所有角色权限点的 **并集（去重）**。

```
用户 张三
 ├─ 角色：管理员        → 权限点 {用户管理, 角色管理, 自定义选项维护, 行业增删, ...}
 ├─ 角色：研究员        → 权限点 {发研报, 创建模拟组合, 改行业研究员名单, ...}
 └─ 实际权限 = 两角色权限点并集
```

**规则：**
- 多角色权限取并集；如有"查看全部数据"这类更强的权限点，覆盖较弱的（如管理员能看全部研报，覆盖研究员"仅本行业"的限制）。
- 一个用户可以没有任何业务角色，此时仅保留**基础只读权限**（查看研报、查看被分享的组合）。
- 用户**软删除**（停用而非物理删），历史研报/组合/审计都引用了用户，不可物理清除。

## 3. 子系统 A：用户与权限管理

### 3.1 实体关系

```
用户 (1) ──< 用户-角色 >── (N) 角色 (1) ──< 角色-权限点 >── (N) 权限点
                                                  │
用户 (1) ──(1:1)── 研究员档案（仅"研究员"角色用户可有，→ ②）
```

### 3.2 角色模型

- **角色可配置**：管理员可新建/编辑角色，并为每个角色勾选权限点。
- **预置角色**（系统初始化时自带，可改可删）：

| 预置角色 | 说明 |
| --- | --- |
| 管理员 | 全权（默认勾全部权限点） |
| 研究员 | 发研报、建/分享组合、维护所属行业信息等 |
| 普通用户 | 只读（看研报、看被分享组合）。不勾角色时也默认此权限。 |

### 3.3 权限点清单

权限点 = 原子操作，由系统提供固定清单。`⚡` 表示留给后续模块细化，本 PRD 先占位。

| 权限点 key | 说明 | 预置归属 |
| --- | --- | --- |
| `用户管理` | 增删改用户、分配角色 | 管理员 |
| `角色管理` | 新建角色、勾选/调整权限点 | 管理员 |
| `自定义选项维护` | 管理选项集与选项 | 管理员 |
| `行业增删` | 增删行业本身（可授权给研究员） | 管理员 |
| `改行业研究员名单` | 维护行业-研究员归属 | 研究员 |
| `股票池管理` ⚡ | 股票出入池 | ③ |
| `出池审批` ⚡ | 审批出池申请 | ③ |
| `发研报` ⚡ | 创建/管理自己研报 | ⑤ |
| `查看全部研报` ⚡ | 跨行业查看研报 | 管理员 |
| `创建模拟组合` ⚡ | 建/分享组合 | ④ |
| `查看研报` | 基础只读 | 普通用户（默认） |
| `查看被分享组合` | 基础只读 | 普通用户（默认） |

> ⚠️ `行业增删` 与 `改行业研究员名单` 是两个独立权限点。管理员可将 `行业增删` 授权给"研究员"角色或某具体用户 —— 授权后可增删行业本身，未授权则只能改行业研究员名单。详见 ②。

### 3.4 用户字段

| 字段 | 说明 | 备注 |
| --- | --- | --- |
| 工号/账号 | 登录标识 | 唯一 |
| 姓名 | — | |
| 邮箱 | 通知 / 分享 | ④分享组合用 |
| 部门 | 所属部门 | |
| 角色（多选） | 管理员 / 研究员 / 普通用户 / 自建角色 | 可多选，取并集 |
| 状态 | 启用 / 停用 | 停用=不可登录 |
| 关联研究员档案 | 仅当角色含"研究员"时 | 指向 ② 的研究员档案 |
| 创建时间 | — | |

### 3.5 权限落地层级

| 层级 | 控制内容 | 实现方式 |
| --- | --- | --- |
| 菜单层 | 可见菜单 | 按角色权限点过滤导航 |
| 操作层 | 按钮显隐（新增/删除/分享） | 按权限点控制 |
| 数据层 | 行级数据范围（如研究员仅本行业） | 按角色 + 关联行业过滤，**②补全** |

## 4. 子系统 B：自定义选项管理（通用配置中心）

研报的"评级""观点"等选项不写死，在配置页维护；设计为通用配置中心，未来任何模块都能来加选项集。

### 4.1 结构：选项集 + 选项项

- **选项集（分组）**：一个集 = 一组同类选项，如「研报评级」「研报观点」「出池原因」。
- **选项项**：每个集下维护若干项。

### 4.2 选项项字段

| 字段 | 说明 | 备注 |
| --- | --- | --- |
| 显示标签 | 如"买入" | 可改 |
| 内部值 / key | 如 `BUY` | 被业务引用，**稳定不改** |
| 排序 | 列表/下拉顺序 | |
| 状态 | 启用 / 停用 | |

### 4.3 铁律

- **已被业务引用的选项只能"停用"，不能物理删除** —— 否则历史研报的评级变空值。
- 内部值 `key` 一旦投入使用不可改；显示标签可随意改。

### 4.4 预置选项集

| 选项集 | 预置项 |
| --- | --- |
| 研报评级 | 买入 / 增持 / 中性 / 减持 / 卖出 |
| 研报观点 | 待 ⑤ 细化 |
| 出池原因 | 待 ③ 细化 |

## 5. 页面与交互（VP UI 规范）

遵循 [`docs/design/ui-spec.md`](../design/ui-spec.md)。要点：

- 整体薄荷绿背景（`--vp-mint-50`）+ 白卡片；顶栏品牌绿（`--vp-green`）。
- 列表用数据表格：正文 14px、表头 12px `--vp-gray-100` 底、偶数行 `--vp-mint-50`、hover `--vp-mint-100`。
- 操作按钮（新增/编辑/删除）放表头右侧或行尾；用胶囊圆角的次级按钮。
- 新增/编辑用弹窗或侧滑；表单字段标签左对齐。
- 状态切换（启用/停用）用开关或分段控件。
- 角色多选用多选下拉/标签输入；权限点用复选框矩阵（角色 × 权限点）。
