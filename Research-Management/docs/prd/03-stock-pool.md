# PRD-03 · 股票出入池管理

> 投研系统的标的管理模块。支持多个命名股票池，每个池可独立配置入池/出池的审批模式（免审批 / 自动审批 / 人工审批）。

**状态**：草案 v1
**最近更新**：2026-08-11
**依赖**：① 配置页面（用户/权限/自定义选项）、② 市场-行业（股票的市场/行业归属）
**被依赖**：④ 模拟组合（标的来源）、⑤ 研报（标的上下文）

---

## 1. 目标与范围

- 支持创建**多个命名股票池**，各自独立管理；
- 每个池可配置**入池模式**和**出池模式**，三选一：免审批 / 自动审批 / 人工审批；
- 每个池**可选绑定市场**（绑市场 or 全局池）；
- 一个股票**可同时存在于多个池**（池是独立集合，互不排斥）；
- 所有出入池操作**留痕**（无论何种模式）。

不在本模块范围：股票行情/基本面数据（外部来源）、组合构建逻辑（→ ④）、研报内容（→ ⑤）。

---

## 2. 核心概念：三模式审批

每个池的**入池**和**出池**分别独立配置为以下三种之一：

| 模式 | 行为 | 产生物 |
| --- | --- | --- |
| **免审批** | 操作即生效 | 仅操作日志 |
| **自动审批** | 系统按预设规则判定，命中即自动通过/驳回 | 申请单（标注"自动"）+ 日志 |
| **人工审批** | 提交申请 → 审批人通过/驳回 | 申请单（待审/通过/驳回）+ 日志 |

> 同一池可不对称：如"核心池"入池=人工审批、出池=人工审批；"观察池"出入池均=免审批。

## 5. 权限衔接（来自 ①）

| 权限点 | 能做什么 | 默认归属 |
| --- | --- | --- |
| `股票池管理` | 创建/编辑池、配置出入池模式、发起出入池操作 | 研究员（操作）、管理员（建池配置） |
| `出池审批` | 审批出入池申请单 | 管理员（可按池指定审批人） |

> 操作层细化：
> - **建池、改池配置**（模式/绑定市场/审批人）：需 `股票池管理` 且偏管理职能，默认管理员。
> - **发起入池/出池操作**：有 `股票池管理` 的用户均可（含研究员）。
> - **审批申请单**：需 `出池审批`，或被指定为该池审批人。
> - 具体权限点是否拆成"建池"与"操作"两个，留待 ① 权限点清单二轮细化。

### 5.1 数据层权限

- 研究员默认仅能操作**其覆盖行业**（② 关系）内的股票；
- 拥有 `股票池管理` 强权限或管理员角色者，不受行业范围限制；
- 审批人可审批其被授权池的申请单。

## 6. 页面与交互

### 6.1 主界面：池列表 → 池详情

- **左侧/顶部**：股票池列表（卡片或表格），显示池名、绑定市场、入/出池模式、池内股票数；
- **右侧/下方**：选中池的详情 —— 池内股票表格 + 出入池操作区。

### 6.2 操作分布

| 操作 | 入口 | 说明 |
| --- | --- | --- |
| 新建/编辑池 | 池列表 | 配置名称、绑定市场、入/出池模式、审批人 |
| 入池（向池加股票） | 池详情 | 按模式走免审批/自动/人工 |
| 出池（从池移股票） | 池详情行操作 | 按模式走免审批/自动/人工 |
| 审批 | 待办/申请单列表 | 人工审批模式用 |
| 查看日志 | 池详情/股票详情 | 全模式操作留痕 |

### 6.3 VP UI 要点

- 遵循 [`docs/design/ui-spec.md`](../design/ui-spec.md)。
- 池列表用白卡片网格（参考 5.5 银行卡片风格）：8px 圆角、1px `#D6E9DE` 边框、hover 边框转品牌绿、阴影升至 `--vp-shadow-md`。
- 池内股票用标准数据表格（14px 正文、12px `#EFF5F1` 表头、`#F2F8F4` 偶数行、hover `#E8F3EC`）。
- 模式切换用货币分段控件（5.6 风格）：免审批 / 自动 / 人工 三段。
- 状态标记（在池/已出池、待审/通过/驳回）用 12px 标签 + 对应色：在池=`--vp-green`、已出池=`--vp-gray-light`、待审=`--vp-gold`、通过=`--vp-green`、驳回=`--vp-danger`。
- 申请单审批用弹窗展示详情 + 通过/驳回按钮。

## 7. 关键规则与约束

- **池是独立集合**：同一股票在多池各自独立的在/出状态，互不影响。
- **池可绑市场也可不绑**：绑市场的池只能放该市场股票；全局池可跨市场。
- **出池为软状态**：PoolStock 置"已出池"保留记录，不物理删，用于历史溯源。
- **全模式留痕**：免审批也写 PoolChangeLog，确保可审计。
- **自动审批规则字段先留空**，待业务规则明确后回填，不影响框架。
- 股票主数据的市场/行业归属来自 ②，不在本模块重复维护行业体系。
