# PRD-04 · 模拟组合管理

> 投研系统的模拟组合模块。研究员创建虚拟组合（选股+权重），记录模拟持仓，用于投资观点验证、讨论或展示。

**状态**：草案 v2
**最近更新**：2026-08-17
**依赖**：① 配置页面（用户/角色/权限）、② 市场-行业、③ 股票出入池（标的来源）
**被依赖**：⑤ 研报（组合可被研报引用）

---

## 1. 目标与范围

- 研究员创建**模拟组合**（虚拟盘，不对接真实账户/交易）；
- 向组合**添加标的**（从③股票池选取，或直接选股票主数据）；
- 设置每只标的的**权重/买入价/数量**；
- 查看组合的**持仓明细、汇总统计**；
- **分享组合**给其他用户（只读或可编辑权限）；
- 所有操作**留痕**（创建/修改/分享记录）。

不在本模块范围：真实交易下单、实时行情对接（外部系统）、绩效归因分析（→ ⑤或后续模块）。

---

## 2. 核心概念

### 2.1 组合类型

| 类型 | 说明 | 可见性 |
| --- | --- | --- |
| **私人组合** | 创建者私有，仅自己可见 | 仅创建者 |
| **分享组合** | 分享给指定用户，支持只读或可编辑 | 被分享者（按权限） |
| **公开组合** | ⚠️ 预留，本次不实现 | 未来全员可见 |

### 2.2 标的来源

组合标的可来自：
1. **③股票池**：从已入池股票中选择（优先推荐，体现池的价值）
2. **股票主数据**：直接选股票（不在池内也可建组合）

> 研究员仅能操作其覆盖行业（② 关系）内的股票；有 `查看全部研报` 等强权限者不受限制。

### 3.5 指标库 (IndicatorLibrary)

> 指标库为组合提供多维度绩效量化指标，支持用户在图表上叠加展示并保存个人偏好。

#### 指标分类（原型实现了以下四类共约20个指标）

| 分类 | 指标 | 说明 |
| --- | --- | --- |
| 收益类 | YTD / 1M / 3M / 6M / 1Y | 区间收益率 |
| 风险类 | 最大回撤（MDD） | 历史最大跌幅 |
| 风险收益比 | 夏普比率（Sharpe） | 收益/波动 |
| 相对基准 | 相对恒生指数 | 与基准对比的超额收益 |

- 单指标展示时 Y 轴显示真实数值（可出现负值，如最大回撤）；
- 多指标叠加时 Y 轴显示相对位置（0%–100% 区间归一化），便于同图比较不同量纲指标；
- 支持预设时间区间（近1月/3月/6月/近1年/上线来/全部）；
- 用户可保存"指标展示设置"（勾选哪些指标、时间区间）到 localStorage，下次打开自动恢复。

#### 指标曲线图交互

- 多指标用不同颜色线条区分；
- 鼠标悬停十字线显示所有指标名称和对应数值；
- 图表上方 chips 展示已选指标，点击 ✕ 移除；
- 支持保存/加载指标展示配置。

## 4. 权限衔接（来自 ①）

| 权限点 | 能做什么 | 默认归属 |
| --- | --- | --- |
| `创建模拟组合` | 新建组合、添加/编辑持仓 | 研究员 |
| `查看全部研报` | 可查看所有组合（不受行业限制） | 管理员 |
| `分享组合` | 将组合分享给其他用户 | 研究员（仅自己的组合） |

### 4.1 数据层权限（行级范围）

- 研究员仅能操作/查看**其覆盖行业**（② 关系）内的股票；
- 研究员仅能操作/查看**自己创建的组合**；
- 管理员可查看/操作所有组合；
- 被分享者按分享时设定的权限操作（只读或可编辑）。

## 5. 页面与交互

### 5.1 主界面：组合列表

- **我的组合**：创建/管理的组合列表（表格或卡片）
- **被分享组合**：他人分享过来的组合（只读或可编辑标记）
- 支持按创建时间/名称/状态筛选

### 5.2 组合详情页（原型：同页展开，不跳转）

点击组合名称后，在组合列表下方直接展开详情，分以下六个区域：

#### 5.2.1 汇总信息栏（KPI Row）

顶部四个指标卡：初始资金 / 当前市值 / 累计收益率 / 最大回撤（MDD）

#### 5.2.2 区间表现图（净值走势图）

- 横轴：时间（支持6档区间：近1月/3月/6月/近1年/上线来/全部）
- 纵轴（左）：组合净值
- 可叠加恒生指数基准线（开关控制）
- 十字线 + tooltip：悬停时同时显示组合值、基准值、各指标数值
- 原型高度：约120px

#### 5.2.3 持仓明细 & 调仓记录（并行双栏）

左右并行布局，各定高5行（超出可滚动）：

- **左侧-持仓明细**：股票代码/名称、市场/行业、权重、买入参考价、数量、估算市值、浮盈/浮亏及收益率
- **右侧-调仓记录**：日期、操作类型、股票代码/名称、变动量、成交价格、成交金额、调仓后权重、操作人

#### 5.2.4 发起调仓

- 点击"发起调仓"按钮 → 弹窗（三态表单：买入/卖出/权重调整）
- 填写：股票（搜索）、操作类型、变动量、价格、备注
- 提交后写入调仓记录

#### 5.2.5 指标库曲线图

- 顶部：指标 chips（已选指标标签，点击 ✕ 移除）+ 时间区间选择（预设6档）
- 图表：多指标折线图，Y 轴自适应（单指标=真值；多指标=相对位置%）
- 支持勾选多个指标叠加展示（不同颜色线条）
- 十字线 tooltip 显示所有指标名称和数值
- 个人偏好保存到 localStorage

### 5.3 添加标的流程

1. 点击"添加标的" → 弹窗
2. 搜索股票（从③股票池 + 股票主数据）
3. 选择后填写：权重或数量（二选一）、买入参考价、备注
4. 确认添加

### 5.4 分享设置

- 点击"分享" → 弹窗
- 选择被分享人（搜索用户）
- 设定权限：只读 / 可编辑
- 确认分享

### 5.5 VP UI 要点

- 遵循 [`docs/design/ui-spec.md`](../design/ui-spec.md)。
- 组合列表用白卡片网格：显示组合名称、持仓数、创建时间、分享状态
- 持仓表格用标准数据表格（14px 正文、12px `#EFF5F1` 表头、`#F2F8F4` 偶数行、hover `#E8F3EC`）
- 权重显示可用进度条可视化（权重占比）
- 涨跌色：港式惯例（上涨=#B23A48，下跌=#20A06E）
- 分享设置用弹窗，选择用户用多选搜索下拉
- 操作按钮（添加/调整/卖出/分享）放持仓表格上方或行尾
- **原型实现补充**：区间表现图高约120px，支持6档时间区间和基准叠加；指标库图高约150px，Y轴根据指标数量自适应（单指标显示真值含负数，多指标显示相对位置%）；持仓/调仓并行两栏各定高5行

## 6. 关键规则与约束

- **组合为虚拟盘**：不涉及真实资金和交易，仅供模拟验证观点
- **权重约束**：单个组合内权重之和建议≤100%，超出时提示但不阻止
- **标的来源**：优先从③股票池选（体现池的价值），也支持直接选股票主数据
- **行业权限**：研究员仅能操作其覆盖行业内的股票
- **分享权限**：仅创建者能分享，且被分享人须在系统内（① 有账号）
- **留痕**：所有操作写入 PortfolioLog，可审计追溯
- **软删除**：组合/持仓均为软删除（停用/卖出），保留历史记录
- **指标库个人化**：指标展示配置保存到浏览器 localStorage，按用户区分，不影响他人
- **Y轴语义**：单指标（尤其是含负值的指标如MDD）使用真值Y轴；多指标叠加时使用相对位置%（0–100%）归一化，便于同图比较不同量纲
- **调仓留痕**：每次调仓（买/卖/权重调整）均写入 Rebalance 记录，含操作人/时间/原因
