# PRD-05 · 研报上传与管理

> 投研系统的核心内容模块。研究人员创建、编辑、分享研报，关联市场/行业/股票/组合，记录投资观点与评级。

**状态**：草案 v2
**最近更新**：2026-08-17
**依赖**：① 配置页面（用户/角色/权限）、② 市场-行业、③ 股票出入池、④ 模拟组合
**被依赖**：无（本系统最终模块）

---

## 1. 目标与范围

- 研究员创建**研报**（标题、正文、附件）；
- 研报关联**市场/行业/股票/组合**，形成完整上下文；
- 支持**评级**和**观点**（来自① 自定义选项）；
- 支持**分享**给其他用户；
- 研报**留痕**（创建/修改/分享记录）；
- 支持按多维度**筛选与搜索**。

不在本模块范围：文档撰写协作（未来扩展）、研报审批流（→ 本模块预留接口，本次不实现）。

---

## 2. 核心概念

### 2.1 研报结构

一份研报包含：

| 字段 | 说明 | 备注 |
| --- | --- | --- |
| 研报标题 | 如"港股科技行业深度报告" | 必填 |
| 研报类型 | 行业报告 / 公司研究 / 宏观策略 / 固收专题 等 | 可扩展枚举 |
| 市场 | 关联市场（②） | 必填 |
| 行业 | 关联行业（②），可多选 | 必填 |
| 股票/标的 | 关联股票（③），可选 | 可不关联（如行业宏观报告） |
| 关联组合 | 关联模拟组合（④），可选 | 作为投资观点支撑 |
| 评级 | 买入/增持/中性/减持/卖出（来自①） | 必填 |
| 观点 | 看好/观望/谨慎（来自①） | 可选 |
| 正文 | 富文本/附件 | 必填 |
| 附件 | PDF/Word/Excel 等 | 可选 |
| 标签 | 自由打标签，便于检索 | 可选 |
| 创建人 | 外键 → 用户（①） | 自动填充 |
| 创建时间 | — | 自动填充 |
| 状态 | 草稿 / 已发布 / 已归档 | 草稿=未完成，发布后可见 |

### 2.2 权限模型

| 权限点 | 能做什么 | 默认归属 |
| --- | --- | --- |
| `发研报` | 创建/编辑自己的研报 | 研究员 |
| `查看全部研报` | 跨行业查看所有研报 | 管理员 |

**数据层权限（行级范围）：**
- 研究员：仅能查看**其覆盖行业**（② 关系）内的研报；
- 管理员 / 有 `查看全部研报`：可查看所有研报；
- 每人仅能编辑**自己创建**的研报。

### 2.3 研报与组合的关联

- 研报可**引用**一个模拟组合（④），作为投资观点的模拟验证支撑；
- 组合的标的应与研报关联的行业/股票匹配；
- 关联组合为可选项，非必填。

## 4. 页面与交互

### 4.1 研报列表页

- **筛选区**：市场 / 行业 / 类型 / 评级 / 标签 / 创建人 / 状态 / 日期范围；各下拉按内容自适应宽度，不撑满整行
- **列表**：研报标题、市场/行业、股票数、评级、创建人、创建时间
- **操作**：新建研报 / 查看详情 / 编辑 / 归档

### 4.2 研报详情页

- **顶部信息卡**：标题、类型、市场-行业、评级/观点标签、创建人/时间、关联组合链接
- **正文区**：研报正文/附件
- **关联股票区**：列出关联的股票列表
- **操作**：编辑 / 归档 / 分享

### 4.3 新建/编辑研报

表单字段：
1. 标题（必填）
2. 类型（必填，下拉选）
3. 市场（必填，下拉选）
4. 行业（必填，多选，级联自市场）
5. 股票（可选，搜索多选，需在已选行业范围内）
6. 关联组合（可选，下拉选，仅显示自己创建的组合）
7. 评级（必填，单选）
8. 观点（可选，单选）
9. 正文（必填，富文本编辑器）
10. 附件（可选，上传）
11. 标签（可选，标签输入）

### 4.4 分享设置

- 点击"分享" → 弹窗
- 选择被分享人（搜索用户）
- 设定权限：只读 / 可编辑
- 确认分享

### 4.5 VP UI 要点

- 遵循 [`docs/design/ui-spec.md`](../design/ui-spec.md)。
- 研报列表用标准数据表格（14px 正文、12px `#EFF5F1` 表头、`#F2F8F4` 偶数行、hover `#E8F3EC`）。
- 评级显示用彩色标签：买入=`--vp-green`、增持=`--vp-blue`、中性=`--vp-gray`、减持=`--vp-gold`、卖出=`--vp-danger`。
- 涨跌色：港式惯例（上涨=#B23A48，下跌=#20A06E）。
- 行业筛选用多选下拉；市场切换后行业级联更新。
- 关联股票用搜索多选下拉，输入股票代码/名称搜索。
- 研报正文区用卡片承载，占主内容区宽度。
- **原型实现补充**：筛选区下拉框宽度 `width:auto; flex:0 1 auto`，按内容自适应，不撑满整行。

## 5. 关键规则与约束

- **行业权限**：研究员仅能查看/操作其覆盖行业（② 关系）内的研报；管理员/有 `查看全部研报` 不受限制。
- **编辑权限**：每人仅能编辑自己创建的研报。
- **软删除**：研报归档（非物理删除），保留历史记录。
- **评级/观点**：来自①自定义选项，已被引用的选项只能停用不能删除。
- **组合关联**：可选，组合创建人须与研报创建人一致（仅能引用自己的组合）。
- **留痕**：所有操作写入 ReportLog，可审计追溯。
