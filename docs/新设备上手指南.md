# 新设备上手指南

> 换一台设备继续投研系统工作 / 查看文档与原型时，照这份做。

---

## 场景速查

| 你的情况 | 怎么做 |
|---|---|
| 新设备能装软件（公司电脑/笔记本） | **clone 到本地**（推荐），体验与原设备无差别 |
| 新设备装不了软件 / 不想装 | 登录 GitHub 网页**只读文档**（原型看不了效果） |

> Private 仓库：无论哪种方式，都必须**登录 Kyra-ddd 账号**才能访问。

---

## 方式一：clone 到本地（推荐）

### 第 1 步 · 检查 / 安装 Git

在新设备终端（PowerShell 或 VSCode 终端）敲：
```powershell
git --version
```
- 有版本号（如 `git version 2.55.0...`）→ 跳到第 2 步
- 报错"找不到 git" → 装 Git：
  ```powershell
  winget install --id Git.Git -e --source winget --accept-package-agreements --accept-source-agreements
  ```
  装完**重启 VSCode / 终端**让 PATH 生效。
  > ⚠️ 公司电脑若禁止装软件，找 IT 协助，或用 Git 便携版（PortableGit）。

### 第 2 步 · 克隆仓库

```powershell
cd c:\Users\你的用户名\Desktop
git clone https://github.com/Kyra-ddd/invest-research-system.git
cd invest-research-system
```
首次会弹 GitHub 登录窗口 → 用 **Kyra-ddd** 账号授权一次。
> ⚠️ 境内访问 GitHub 可能不稳，`clone` 失败就多重试 / 换网络 / 问 IT 要代理。

### 第 3 步 · 看文档

用 VSCode 打开整个文件夹：
```powershell
code .
```
- `docs/prd/` 下的 `.md` 文件：按 `Ctrl+Shift+V` 预览
- 先读 `README.md`（进度）和 `CLAUDE.md`（项目背景与 UI 铁律）

### 第 4 步 · 看原型效果

```powershell
start prototypes\02-industry-analyst.html
```
浏览器打开，改文件名看其他页面（`01-config.html`、`03-stock-pool.html`）。三个页面侧栏互通。
> 原型用了 Google Fonts，境内加载可能慢；加载失败会用系统字体兜底，不影响查看。

### 第 5 步 · 继续干活

- 装好 Claude Code（VSCode 扩展）→ 打开本文件夹 → Claude 自动读 `CLAUDE.md` 接上上下文
- 改完提交并推回：
  ```powershell
  git add .
  git commit -m "说明"
  git push
  ```
- 回原设备时 `git pull` 拉最新

## 方式二：网页只读（退路）

装不了 Git / 上不了 GitHub clone 时：

1. 浏览器打开 [github.com/Kyra-ddd/invest-research-system](https://github.com/Kyra-ddd/invest-research-system)
2. 登录 **Kyra-ddd** 账号
3. 点进 `docs/` 读 Markdown（GitHub 自动渲染）
4. ⚠️ `prototypes/` 里的 `.html` 只能看代码，**跑不出效果**

---

## 常见问题

- **`git` 命令找不到** → 重启 VSCode/终端；或 Git 没装/没进 PATH。
- **clone 报 Connection reset / 超时** → 境内网络问题，多重试或换网络/代理。
- **弹认证要密码** → GitHub 不认账号密码，要 Personal Access Token（github.com/settings/tokens 生成，勾 `repo` 权限）。
- **PowerShell 开头红字报 profile 错误** → 无害，忽略（不影响 git）。
